# Orttaai 0.5.0

Released November 10, 2026.

Orttaai 0.5.0 makes editing what you said as quick as saying it, as Orttaai 1.21 does on the Mac.

## Download

- **Windows**: `Orttaai_0.5.0_x64-setup.exe` (or the `.msi`)
- **Linux**: `.deb` (Ubuntu, Debian), `.rpm` (Fedora) or `.AppImage`

Existing installs update themselves from the sidebar button.

## Voice editing

- **Tap Right Shift to edit.** Tap it, say how to change your text ("make this more formal"), and tap it again. Turn it on in Settings › Text › Voice Editing. Shift works as usual while you type: only a quick tap on its own counts. Windows and X11; Wayland doesn't let apps watch a single key, so use the edit shortcut there.
- **Your dictation shortcut edits a selection.** Select text, press your dictation shortcut and say an instruction like "make this shorter", "fix the grammar" or "turn this into a list". Anything else you say replaces the selection, as before. The rules are strict on purpose: "put it on the calendar" is still typed. English only, and only in apps that show their text to accessibility (UI Automation on Windows, AT-SPI on Linux); elsewhere use the edit shortcut or Right Shift.
- **Edit your last dictation with nothing selected.** Right after dictating, press the edit shortcut (or tap Right Shift) and say "make that more formal". Orttaai finds what it just typed in that window (within 10 minutes), selects it and rewrites it.

## Careful by default

- Without a local model running, the dictation shortcut types your words exactly as in 0.4.
- An edit that doesn't land never loses your words: they're saved to History, and text Orttaai selected for an edit is put back as it was.
- If the selection changes while you speak the instruction, nothing is pasted beside it.
- Address bars and search boxes, read-only text (web pages, PDFs) and password fields are never edited from the dictation shortcut, and a Coach practice take is never mistaken for an edit.
- Voice edit refuses terminals instead of pressing Ctrl+C there, which would stop the program running in them.
- In VS Code, Cursor and Windsurf, an edit with nothing selected no longer rewrites the line the cursor is on.
- An app that stops answering can't hold up dictation: Orttaai stops waiting on it after a couple of seconds.
- If your keyboard layout has no Right Ctrl (mapped to Compose, say), Tap Right Shift to Edit still works, and each key shows its own message in Settings.
- Right Shift works inside Orttaai's own window too.
