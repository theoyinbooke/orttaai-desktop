# Orttaai 0.7.1

Released November 19, 2026.

Orttaai 0.7.1 offers the speed test to everyone, so each PC dictates as fast as it can without a trip to Settings.

## Download

- **Windows**: `Orttaai_0.7.1_x64-setup.exe` (or the `.msi`)
- **Linux**: `.deb` (Ubuntu, Debian), `.rpm` (Fedora) or `.AppImage`

Existing installs update themselves from the sidebar button.

## Speed test card

- **A card offers the speed test once**: right after Setup, or at launch after updating if you haven't run it and Decode Threads is on Auto. Click **Run Speed Test** and keep going: it runs in the background for about a minute, dictation keeps working, and a message tells you the thread count it chose and how much faster that is. **Not Now** puts the card away; the test stays in Model › Performance.
- **The speed test runs in the background** from Model › Performance too, and the row keeps the last result. Open it during a test to see its progress.
- Milestone celebrations wait for the card, as they do for What's New.
