# Orttaai 0.7.0

Released November 19, 2026.

Orttaai 0.7.0 finds the fastest setting for your PC.

## Download

- **Windows**: `Orttaai_0.7.0_x64-setup.exe` (or the `.msi`)
- **Linux**: `.deb` (Ubuntu, Debian), `.rpm` (Fedora) or `.AppImage`

Existing installs update themselves from the sidebar button.

## Speed Test

- **Model › Performance › Speed Test** times a few seconds of sample speech with the speech model you use (Express or Whisper) at several thread counts, then sets Decode Threads to the fastest. PCs differ too much in their cores, power settings and cooling for one rule to suit them all; this measures yours. It takes about a minute, and dictation keeps working while it runs.
- Run it again after changing the speech model. Set Decode Threads back to Auto to use the built-in rule.

## Notes

- Using Intel or AMD graphics chips (DirectML) for speech was looked at and isn't in this release: the runtime it needs can't load the Fluid Speech models yet. Details are in `docs/performance.md`.
